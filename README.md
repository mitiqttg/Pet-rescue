A Flutter project that display a Home Page of a pet rescue service.

- Home page:
    - Introduction to our service
    - About us

- Rescue page:
  - Cards of pets: Pet name, breed, age, traits, images, video
  - Giving one shelter
  - Donation

- Rehome page:
  - Same structure as Rescue page
  - Giving one shelter
  - Donation


- App bar:
    - Title: Petlassa
    - Curren page location
    - Search bar 🔎: Search for words in the entire pages of the service

- Drawer:
    - Home 🏠
    - Rescue 🐕
    - Donation 💸
    - Log in / Register 👋
    - Theme button
